# Server Toolkit 🛠️

Boîte à outils Bash pour l'administration et le diganostic de serveurs Linux.

## Script disponibles
- 'audit-users.sh' - audit des comptes utilisateurs actifs
- 'analyse-logs.sh' - analyse des logs pour identifier les IPs générant des erreurs
- 'healthcheck.sh' - script pour identifier les requêtes HTTP à problèmes
